# ⚒️ ProofForge

### Generate code. Test assumptions. Build with confidence.

**ProofForge** is a Gemma 4-powered coding assistant that transforms natural-language prompts into code. It also features a built-in prime-checker testing demo to show how test cases can help identify bugs in a program.

Built for the **Best Use of Gemma 4** hackathon challenge.

---

## ✨ Features

- 🤖 **AI Code Generation** — Generate code from simple natural-language instructions using Gemma 4.
- ⚡ **Simple Interface** — Submit coding prompts and view generated solutions in a clean, easy-to-use workspace.
- 🧪 **Testing Demonstration** — Experiment with a prime-checker demo using correct and buggy implementations.
- 🔍 **Bug Detection** — See how test cases reveal errors and help evaluate program behavior.
- 🛠️ **Modern Tech Stack** — Built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Getting Started

### Prerequisites

- Node.js installed
- npm installed
- A Google AI API key with access to the configured Gemma model

### 1. Clone the repository

```bash
git clone https://github.com/Ankit69Dev/Proof-Forge.git
cd proofforge
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure your API key

Create a `.env.local` file in the project root:

```env
GEMINI_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your own API key. **Never commit your API key or share it publicly.**

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🧪 Try It Out

1. Open ProofForge in your browser.
2. Enter a coding task or choose an example prompt.
3. Generate a solution using Gemma 4.
4. Explore the prime-checker demo.
5. Switch between the correct and buggy implementations and run the test cases to observe the results.

> **Note:** The prime-checker tests are a controlled demonstration. They test the demo's predefined implementations, not the code generated by Gemma 4. Generated code should always be reviewed and tested separately before use.

## 🎯 Why ProofForge?

AI can make writing code faster, but generated code should not be trusted without review. ProofForge brings code generation and the idea of testing together, encouraging developers to look beyond a solution that simply appears correct.
